[SOURCE: Python Core Guide - Section 1.1: Variables & Data Types]
Python is dynamically typed. Variables are created upon assignment. Primitive types include int, float, str, and bool. Strings are immutable sequences of Unicode characters. Type conversion can be performed explicitly using built-in constructors like int("42") or float(10).

[SOURCE: Python Core Guide - Section 1.2: Control Flow]
Python uses indentation instead of curly braces to define blocks of code. The 'for' loop iterates over iterables like lists or ranges using 'for item in iterable:'. The 'while' loop executes as long as a condition evaluates to True. The 'break' statement terminates the nearest enclosing loop prematurely, whereas 'continue' skips the rest of the current iteration and jumps to the next.

[SOURCE: Python Core Guide - Section 1.3: Functions & Scope]
Functions are defined using the 'def' keyword followed by function name and parameters. Return statements pass values back to caller; if omitted, the function implicitly returns None. Python resolves variable scope using the LEGB rule (Local, Enclosing, Global, Built-in). To modify a global variable inside a local function scope, the 'global' declaration keyword must be used.

[SOURCE: Python Core Guide - Section 2.1: Lists and Tuples]
Lists are mutable, ordered collections written with square brackets []. Elements can be added using append() and removed using pop(). Tuples are immutable, ordered collections written with parentheses (). Because tuples cannot be altered after creation, they are hashable and can serve as dictionary keys, unlike lists. List comprehensions provide a concise syntax [x**2 for x in nums if x > 0].

[SOURCE: Python Core Guide - Section 2.2: Dictionaries & Sets]
Dictionaries are mutable collections of key-value pairs written as {key: value}. Keys must be immutable and hashable types. Looking up values by key has an average time complexity of O(1) due to underlying hash table implementation. Sets are unordered collections of unique elements. Sets support mathematical set operations such as union (|), intersection (&), and difference (-).

[SOURCE: Python Core Guide - Section 3.1: OOP & Classes]
A class is a blueprint for objects. The '__init__' method is the constructor called automatically upon instantiation. The first parameter of instance methods is conventionally named 'self', which refers to the specific instance being operated on. Instance attributes are bound using 'self.attribute_name'.

[SOURCE: Python Core Guide - Section 3.2: Inheritance & super()]
Inheritance allows a subclass to inherit attributes and methods from a superclass. To call a method or constructor from the parent class, the 'super()' built-in is used, such as 'super().__init__()'. Method overriding occurs when a subclass defines a method with the same name as a superclass method, substituting child-specific behavior.

[SOURCE: Python Core Guide - Section 4.1: File Handling]
Files should be accessed using the 'with' statement context manager (e.g., 'with open("file.txt", "r") as f:'). The context manager automatically guarantees that the file stream is closed properly even if exceptions occur. Standard file modes include 'r' (read), 'w' (write/overwrite), and 'a' (append).

[SOURCE: Python Core Guide - Section 4.2: Exception Handling]
Exceptions are handled using 'try' and 'except' blocks. Code prone to error is placed in 'try'. If an exception occurs, execution jumps to matching 'except ExceptionType:' block. The 'else' block executes only if NO exceptions were raised in 'try'. The 'finally' block executes unconditionally, making it ideal for cleanup routines.
